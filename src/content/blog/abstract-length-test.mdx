# Feature Tour: Style, Structure, and Signal

This post is built to exercise the blog styles. It uses **bold**, _italic_,
`inline code`, blockquotes, lists, tables, math, and a chart. It also includes a
margin note and footnotes.[^why-not]

<MarginNote title="Sidenote">
This is a margin note component. It should float on wider screens and stack
inline on smaller screens.
</MarginNote>

## Outline of the Styling

1. Headings and subheadings for hierarchy.
2. Lists for rhythm and spacing.
3. Tables for data density.
4. Code blocks for syntax highlighting.
5. Quotes for emphasis and voice.

> A blockquote should feel distinct but not overpower the body text.

## Mathematical Formula

Inline math looks like $e^{i\pi} + 1 = 0$, while a displayed equation should
stand on its own:

$$
S(t) = \int_0^t \left( \alpha x^2 + \beta x + \gamma \right) \, dx
$$
