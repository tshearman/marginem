Common Lisp `run` fences now compile and execute during the Astro build. Just like with Python or Haskell, an exception or `error` call aborts the build so faulty demos never reach production.

```lisp run

(DEFUN FACTORIAL (N)
  (IF (<= N 1)
      1
      (* N (FACTORIAL (- N 1)))))

(LET ((VALUE (FACTORIAL 5)))
  (FORMAT T "5! = ~A~%" VALUE)
  (WHEN (/= VALUE 120) (ERROR "Factorial logic regressed!")))
```

Longer helpers benefit from the `src=...` meta attribute so we can keep them in `src/snippets/` while still rendering the file inline and executing it at build time.

```lisp run src="../../snippets/harmonic.lisp"
```
