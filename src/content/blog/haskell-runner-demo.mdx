Our MDX pipeline now executes `run` blocks written in **Haskell**. That means we get the same guarantees as the JavaScript and Python demos—compile errors, failed assertions, or unexpected output will stop the build.

```haskell run
import Control.Monad (when)

main :: IO ()
main = do
  putStrLn "Quick Haskell sanity check"
  let squares = [n * n | n <- [1 .. 5]]
  print squares
  when (last squares /= 25) $
    error "List comprehension misbehaved!"
```

Longer helpers can live in `src/content/snippets/` so multiple posts can reuse them while still rendering and executing inline during builds.

```haskell run src="../snippets/harmonic.hs"
```
