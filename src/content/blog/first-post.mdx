### Runnable snippets

Add `run` to the meta string of any fenced JavaScript block and the snippet executes at build time. Logs and returned values are captured under the block so broken demos never ship.

```js run
const fibonacci = (count) => {
  const seq = [0, 1];
  for (let i = 2; i < count; i++) {
    seq[i] = seq[i - 1] + seq[i - 2];
  }
  return seq;
};

'First eight terms:', fibonacci(8);
```

```js run
const average = (...values) => values.reduce((sum, value) => sum + value, 0) / values.length;
average(2, 4, 6, 8);
```

### Interactive plots

Drop in small clients such as Plotly, D3, or Observable components using MDX. Astro hydrates only what the page needs.

      y: Array.from({ length: 50 }, (_, i) => Math.sin(i / 5)),
